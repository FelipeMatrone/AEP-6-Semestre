# CLAUDE.md

**Leia `AGENTS.md` na raiz antes de qualquer coisa.** As convenções do
repositório — stack, camadas, Definition of Done, commits, branches, trabalho
assistido por IA — vivem lá, porque `AGENTS.md` é lido por praticamente toda
ferramenta de IA e este arquivo só pelo Claude Code.

Antes de escrever código no backend: `docs/padroes.md`.
Antes de escolher o que fazer: `docs/backend-tarefas.md`.

## Específico do Claude Code

- Commits **não levam rodapé de atribuição** (configurado em
  `.claude/settings.local.json`, que não é versionado — quem quiser o mesmo
  comportamento precisa criar o arquivo na própria máquina).
